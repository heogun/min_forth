# 세운상가 부품 구매 목록 — Minimal 64x4 Redux 1.4

## 적용 범위

- **Revision 1.4 Redux PCB 한 대**를 제작하기 위한 목록이다. Rev1.1이나 다른 PCB에는 그대로 적용하지 않는다.
- 작업 공간의 `minimal64/Revision 1.4 Redux/KiCAD9/` 회로도와 공식 매뉴얼의 Rev1.4 BOM을 대조했다. 매뉴얼의 일부 참조번호 오기는 회로도를 우선했다.
- 표의 수량은 **실장 수량**이며 예비품은 별도다. 매장별 재고·가격·대체품 적합성은 확인하지 않았다.
- 에뮬레이터 검증과 실제 하드웨어의 전기적·타이밍 검증은 다르다. 이 문서는 실기 제작 성공을 보증하지 않는다.

> 매장 요청 문구: “Minimal 64x4 Redux 1.4 제작용입니다. 로직은 표의 HC/HCT 계열 DIP형, 메모리도 PDIP형으로 주세요. 임의 호환품 대체 전에는 확인 부탁드립니다.”

### IC 구매 주의

- `74HC`를 `74LS`, `74AC`, `74HCT` 등으로 임의 대체하지 않는다. 같은 논리 기능이라도 입력 임계값·구동 특성·전파 지연이 다르다.
- **U9는 74HCT132**다. PS/2 입력 조건을 고려한 부품이므로 HC132로 임의 변경하지 않는다.
- **74HC4002와 CD4002는 이름만 보고 대체하지 않는다.**
- 타이밍에 민감한 설계다. 출처 불명 재마킹·중고 탈거품보다 제조사와 출처가 확인되는 제품을 권한다. 동일 제조사라도 실제 타이밍 확인이 필요할 수 있다.
- 예비품 권장: HC161 2개, 다른 로직은 예산에 따라 종류별 1개. 예비품은 위 실장 수량에 포함하지 않았다.

## 2. 메모리·발진기 — 메모리 IC 6개, 발진기 1개

| 구매 | 부품 | 수량 | 구매 조건 / 용도 |
| --- | --- | ---: | --- |
| [ ] | SST39SF040 / SST39SF040A | 4 | **512KB, 70ns급, PDIP-32**. 정확한 주문번호·데이터시트·기록기 지원 확인 |
| [ ] | AS6C1008 SRAM | 1 | 128K×8, PDIP-32, 55ns 또는 70ns급. U34 시스템 RAM |
| [ ] | AS6C62256 SRAM | 1 | 32K×8, PDIP-28, 55ns 또는 70ns급. U36 VRAM |
| [ ] | **16MHz 발진기 모듈** | 1 | **5V, DIP-14 크기의 4핀 모듈**. 전원·출력·Enable/NC 핀 배치 확인 |

- **16MHz 크리스털 단품이 아니다.** 전원을 넣으면 클록을 출력하는 발진기 모듈이다. CPU 클록은 보드에서 8MHz로 만든다.
- FLASH 4개는 제어 ROM 3개와 프로그램 저장용 1개다. 구형 BOM의 SST39SF010을 잘못 구매하지 않는다.
- SRAM은 용량뿐 아니라 패키지·핀 배치·전압·속도를 함께 확인한다. 시스템 RAM과 VRAM을 같은 부품으로 간주하지 않는다.

## 3. 저항·커패시터

저항은 공식 BOM의 **축형 0207, 0.6W급**을 기준으로 요청한다. PCB 리드 간격은 7.62mm다.

| [ ] | 4.7kΩ 저항 | 4 | R1, R3, R4, R5 |
| [ ] | 150Ω 저항 | 2 | R6, R26 |
| [ ] | 68Ω 저항 | 2 | R7, R8 |
| [ ] | 100Ω 저항 | 1 | R25 |
| [ ] | 470Ω 저항 | 15 | R2, R9..R22. R27 제외 |
| [ ] | R27 조정용 저항 | 1 | 회로도 기본값 470Ω. 아래 설명 참고 |
| [ ] | **470Ω 저항 네트워크** | 1 | RN1, **SIP-9, 공통핀형, 내부 저항 8개** |
| [ ] | 100nF 세라믹 커패시터 | 20 | C1..C20, `104`, 리드 간격 2.5mm. 정격 16V 이상 권장 |
| [ ] | 22pF 세라믹 커패시터 | 2 | C32, C33, `22p` 또는 `220`. C0G/NP0 권장, 리드 간격 2.5mm |

### R27과 저항 네트워크

- **R27은 클록 타이밍 조정용**이다. 매뉴얼에 따르면 보통 200~470Ω이지만, IC 지연 특성에 따라 0Ω이 필요할 수도 있다.
- **0Ω·200Ω·330Ω·470Ω을 몇 개씩** 챙겨두면 좋다. 470Ω도 실장용 15개에 더해 R27용과 예비분을 구매한다.
- 동작 불량을 무조건 R27 탓으로 보고 임의 변경하지 않는다. 전원·납땜·ROM을 먼저 확인하고, 가능하면 오실로스코프로 U24의 14번 핀과 U10의 2번 핀을 CLK 기준으로 비교한다. 자세한 절차는 공식 매뉴얼의 Troubleshooting을 따른다.
- RN1은 **공통핀형(bussed/star)**이다. 독립 저항형과 혼동하지 말고, 실장 때 공통핀 표시 방향을 확인한다.
- 저항·커패시터는 각각 몇 개씩 예비품을 권한다.

## 6. 구동·ROM 기록용 준비물

이미 가진 장비는 중복 구매할 필요 없다.

- [ ] **USB–TTL UART 어댑터 1개**: 500,000bps와 **7N2** 지원, 보드와 호환되는 신호 전압 확인.
  - **RS-232 전압 출력 제품은 연결하지 않는다.**
  - “5V 전원 출력”과 “TX/RX 신호의 5V 호환”은 별개다. 3.3V 전용 입력에 보드의 5V 출력을 직결하지 않는다.
  - 헤더 핀 순서는 제품마다 다르다. 바로 꽂지 말고 GND·5V·TX·RX를 확인한다.
- [ ] **SST39SF040 기록 지원 FLASH 프로그래머**, 또는 매장의 ROM 기록 서비스.
  - 정확한 칩명과 PDIP-32 지원을 확인한다. 흔한 24/25계열 전용 CH341A 세트로 그대로 대체할 수 없다.
  - 기록 후에는 **read-back/verify**를 요청한다.
- [ ] 안정적인 **정전압 5V 전원**과 적절한 케이블.
  - 공식 매뉴얼의 Redux 보드 소비전류는 약 200~250mA지만 부품·주변장치에 따라 달라진다. 키보드와 전원 경로의 허용전류까지 고려한다.
  - 최초 통전에는 전류 제한이 가능한 전원을 권한다.
- [ ] 기본 PS/2 키보드: Scan Code Set 2, 복잡한 양방향 초기화 없이 동작하는 제품.
  - USB 키보드에 수동 PS/2 젠더만 꽂는 방식은 키보드 자체가 PS/2를 지원해야 한다.
- [ ] VGA 모니터와 케이블: 640×480, 60Hz 입력 지원. 최초 시험은 LCD 권장.
- [ ] 인두·납·플럭스·흡납 도구·니퍼·멀티미터·ESD 보호 용품.
- [ ] 가능하면 오실로스코프와 짧은 접지 연결이 가능한 프로브: 클록 타이밍 문제 진단용.

## 7. 방문 전·매장·조립 체크리스트

### 방문 전

- [ ] 가진 PCB가 **Redux 1.4**인지 확인한다.
- [ ] 이 문서와 VGA·PS/2 커넥터 풋프린트 도면을 준비한다.
- [ ] 특히 **HC590·HC377·HC4002·SRAM·FLASH의 DIP 재고**를 전화로 문의한다. 현장 재고는 보장되지 않는다.
- [ ] 보유 부품·장비와 예비품 수량을 구분해 표시한다.

### 매장에서

- [ ] 숫자뿐 아니라 **HC/HCT 계열, 패키지, 속도, 정격전압**을 확인한다.
- [ ] 메모리 주문번호와 발진기 핀 배치를 확인한다.
- [ ] 커넥터 다리·고정 탭과 소켓 폭을 도면에 대조한다.
- [ ] 출처와 교환 가능 조건을 확인하고, 부품은 품명별로 나눠 포장한다.

### 조립·최초 전원 투입

- [ ] 전원을 끈 상태에서 납땜 브리지와 5V–GND 단락 여부를 검사한다.
- [ ] IC 1번 핀 방향, 소켓 안으로 접힌 다리, RN1 공통핀 방향을 검사한다.
- [ ] UART 연결은 **전원을 끈 상태에서** 한다. GND·5V를 확인하고 TX→RX, RX→TX로 연결한다.
- [ ] UART 전원과 외부 전원을 무심코 동시에 연결하지 않는다. 전원 역공급 가능성을 확인한다.
- [ ] 공식 매뉴얼 권고대로 UART 배선을 고정한 뒤 USB 플러그 쪽에서 전원을 연결·분리한다. 접지 불량 핫플러그는 FLASH 내용을 손상시킬 수 있다.
- [ ] 최초 통전은 전류 제한 상태에서 진행하고 이상 발열·전압 강하가 있으면 즉시 끈다.
- [ ] RESET 후 부팅을 확인한다. **구형 CRT는 영상 blanking이 정상화되기 전에 연결하지 않는다.** 공식 매뉴얼은 이 상태에서 CRT 손상 가능성을 경고한다.

## 8. 우리 프로젝트의 ROM 기록 안내

**온라인의 구형 ROM 대신 이 작업 공간에서 검증한 수정 제어 ROM을 사용한다.** 네 칩의 역할을 표시하고 서로 바꾸지 않는다.

| PCB 위치 | 역할 | 기록할 파일 |
| --- | --- | --- |
| U25 | 제어 ROM LSB | `minimal64/Revision 1.4 Redux/FLASH Images/ctrl_lsb.bin` |
| U23 | 제어 ROM MSB | `minimal64/Revision 1.4 Redux/FLASH Images/ctrl_msb.bin` |
| U21 | 제어 ROM HSB | `minimal64/Revision 1.4 Redux/FLASH Images/ctrl_hsb.bin` |
| U31 | 프로그램 저장 FLASH | Forth 사용 시 최신 `minforth/build/flash.bin` |

각 파일은 512KB 이미지다. 매장에 기록을 맡기면 파일명·대상 칩 표시와 기록 후 검증을 함께 요청한다. `minforth/build/flash.bin`은 MinOS와 Forth를 포함하는 저장 이미지이며, 제어 ROM을 대신하지 않는다. Forth 실행은 MinOS 부팅 후 `minforth` 명령으로 한다.

이미지 준비는 저장소 루트에서 실행한다.

```sh
# 수정 제어 ROM의 SHA-256과 CSV 일치 검사
python3 minredux/verify_rom.py

# 어셈블러가 없을 때 먼저 빌드
clang++ -O2 -std=c++11 minforth/tools/asm.cpp -o minforth/tools/asm

# 최신 Forth를 저장 FLASH 이미지에 반영
python3 minforth/tools/build.py minforth/forth/kernel.fs minforth 0x1000
```

기본 UART 설정은 **500,000bps, 7 data bits, no parity, 2 stop bits, flow control 없음, 줄바꿈 LF**다. HEX 업로드 때 매뉴얼은 초기값으로 줄당 10ms 지연을 권한다.
